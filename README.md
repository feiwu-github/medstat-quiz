# 医学统计学 · 选择题练习

公开网址：**https://feiwu-github.github.io/medstat-quiz/**

手机或平板可以直接打开这个网址，不需要电脑；建议在 Safari/Chrome 里选择「添加到主屏幕」，用起来更接近一个 App。

一个单文件网页，直接双击 `index.html` 也能做题。

## 使用

1. 双击 `index.html`，或用浏览器打开它。
2. 点击 A–E 选项，再点「提交答案」。
3. 提交后会立即显示：
   - 回答正确 / 回答错误
   - 正确答案（字母 + 选项内容）
   - 解析（原题有解析时显示）
4. 点「下一题」继续；点「上一题」返回。
5. 点「答题卡」可以跳到任意一题，答对/答错会分别标绿/标红。
6. 点「重新打乱」重新随机排序并清空本轮作答；点「重置」只清空作答，不换顺序。

快捷键：

- `A`–`E` 或 `1`–`5`：选择选项
- `Enter`：提交；已提交时进入下一题
- `←` / `→`：上一题 / 下一题
- `Esc`：关闭答题卡

答题进度只保存在当前页面，刷新页面会重新开始；没有账号、没有联网请求。

## 跨浏览器与手机/平板

`index.html` 是单文件页面，CSS、JavaScript 和 399 道题都内嵌在里面，没有外部字体、图片或接口依赖。

- 桌面浏览器：Safari、Chrome、Edge、Firefox 都可以直接打开。
- 手机/平板：页面是响应式的，390×844（手机）和 820×1180（平板）实测没有横向溢出；手机端会自动隐藏题库说明条，390×844 下一屏能放下题目、选项和提交按钮。360×640 这种很小的屏幕可能需要轻微上下滚动。
- 现代浏览器（Safari 15+、Chrome/Edge 100+、Firefox 100+）体验最好；很旧的浏览器可能不支持深色模式或磨砂背景，但不影响做题。

最可靠的手机/平板打开方式，是让电脑和手机连同一个 Wi-Fi，然后在电脑上启动一个本地静态服务器：

```bash
cd quiz
python3 -m http.server 8000
ipconfig getifaddr en0
```

假设 `ipconfig` 输出 `192.168.1.23`，手机/平板浏览器访问：

```text
http://192.168.1.23:8000/
```

电脑的 Python 进程要保持运行；macOS 如果弹出防火墙提示，允许 Python 接入局域网即可。只在自己信任的家庭/个人网络里这样用，不要把这个端口暴露到公网。

也可以把 `index.html` 通过 AirDrop、邮件或网盘发到手机上，再用支持本地 HTML 的浏览器/文件 App 打开；iOS 的“文件”预览有时不执行完整 JavaScript，所以局域网地址更稳。
